# 模型服务平台固定规则

- 创建时选择火山引擎、OpenAI、DeepSeek 或其他兼容平台；保存后 `platformKey` 固定，不受是否启用或是否为当前配置影响。
- 编辑仍可修改名称、模型 ID、密钥、超时、上下文和输出上限。预设平台继续使用其固定地址，自定义平台的地址仍受 HTTPS 白名单限制。
- `PATCH /api/admin/model-profiles/llm/:id` 允许省略平台或传入相同平台；传入不同平台返回 400，不写入配置、不刷新运行时。
- `POST /api/admin/model-profiles/llm/test` 指定 `profileId` 时也必须保持该配置的平台，不能借用旧配置密钥测试其他平台。
- 编辑弹窗中“新建替代配置”打开新的平台选择流程，不复制旧密钥。替代当前配置时，点击“创建并设为当前”先创建、再调用现有激活接口；原配置保留。
- 创建成功但切换失败时，弹窗进入新配置的编辑状态，可点击“设为当前”重试，不重复创建。替代非当前配置不会自动改变当前模型。
- 本轮不修改 Agent 或 Provider 的模型输出、工具调用和业务行为，不迁移或删除已有配置。

## 配置状态与列表

- 当前使用：单独一行置顶，只将实际默认配置标为当前模型。
- 备用：已开启但非当前的配置，不自动承担请求或故障切换，需手动“设为当前”。
- 已停用：放在其他配置末尾；“恢复为备用”不改变当前模型。
- 列表、编辑弹窗和删除时的替代模型选择统一使用以上文案；配置及其密钥不因分组或文案调整而改变。
