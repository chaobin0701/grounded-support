# Embedding 服务管理

后台入口：`/admin/embedding-services`。独立权限为 `embedding_profiles.read` 和
`embedding_profiles.manage`，默认仅超级管理员拥有。知识库管理权限只允许选择
已启用配置，不再隐含向量服务的密钥管理权限。

## 配置与测试

- 支持火山引擎方舟（标准或多模态接口）、OpenAI、其他 OpenAI Compatible 服务。
- 平台创建后固定。自定义 HTTPS 地址需先加入部署环境的 `EMBEDDING_ALLOWED_BASE_URLS`。
- API Key 使用现有 `SecretBox` 加密，接口仅返回脱敏前后缀，浏览器不持久化密钥。
- 测试发送一条真实请求，展示耗时、预期维度、实际维度及失败原因，不保存或启用配置。
- 未使用配置可以修改接口、模型和维度。被知识库、文档向量或任何索引版本引用后，向量空间锁定。
- 密钥、名称、超时和批量参数可修改；密钥轮换不会改变向量空间，历史索引也读取最新密钥。
- 使用中的配置不能停用；任何被引用的配置不能删除。归档与历史引用仍受删除保护。

不设置全局默认 Embedding 模型。每个知识库独立选择，状态为「被 N 个知识库使用」、
「未使用」或「已停用」。已有部署环境凭据可以继续使用，编辑保存新密钥后转为后台管理。

## 更换知识库模型

1. 创建并测试新配置。
2. 在知识库「设置」选择配置，保存待应用设置。
3. 点击「构建新索引」，等待构建完成。
4. 点击「应用索引」。如需回滚，切换到保留的旧版本。

已有在线版本继续使用原模型；旧式即时索引会在切换向量模型前自动冻结为版本。
新索引构建失败时不替换在线版本。召回测试可选择在线索引或待应用配置下的当前文档。
首次上传的高级知识库仍支持即时检索；向量模型改变后使用版本切换。

## 向量隔离

文档向量升级为可变维度 `vector` 存储，当前配置允许 1–4096 维。
文档入库、版本构建和问题向量统一使用同一客户端及配置凭据。
向量空间指纹由接口类型、规范化地址、模型 ID 和维度生成，不再仅按模型名匹配。
数据库先筛选兼容维度和指纹，再计算距离，避免不同模型或维度混用。
旧向量仅在明确匹配原知识库配置时绑定；无法确认归属的旧向量保留原数据，并使用全文召回，
可通过重建索引恢复向量召回。

## 管理接口

基础路径 `/api/admin/model-profiles/embedding`，需管理员 Bearer Token。

| 方法 | 路径 | 功能 |
| --- | --- | --- |
| GET | `/` | 配置与使用数量（无明文密钥） |
| GET | `/metadata` | 平台预设及维度限制 |
| POST | `/` | 创建加密配置 |
| PATCH | `/:id` | 编辑配置 |
| PATCH | `/:id/status` | 停用或恢复 |
| DELETE | `/:id` | 删除无引用配置 |
| GET | `/:id/usage` | 知识库、在线与历史索引使用关系 |
| POST | `/test` | 使用表单参数测试连接，可传 `profileId` 使用原密钥 |

创建、编辑、测试、状态变化、删除与索引切换均写审计记录，不记录密钥。
