# 禾序官网项目规则

## 项目定位

- 这是禾序智能科技有限公司的独立中文官网 npm 项目，品牌为学习用途的虚拟设定。
- 技术栈为 Vue 3、TypeScript、Vite、Vue Router；独立安装、开发和构建，不依赖 `../web/src`。
- 默认预览端口 8849，API 代理到现有 3000 服务；保留原有 8848 后台和聊天应用。
- 不修改管理员权限、Agent、产品数据库或现有项目配置来满足纯官网需求。

## 设计方向

视觉主张：以深青绿、暖白、自然生活图像和有序留白，呈现温暖、可靠的传统家电品牌。

内容顺序：首页品牌主张 → 精选产品 → 品牌理念 → 服务入口；产品页直接显示分类、搜索与产品网格。

交互主张：短暂的首屏淡入、产品悬停反馈、菜单与筛选状态过渡；不使用自动轮播、强视差、滚动劫持、持续粒子或大面积 WebGL。

- 设计参考 Furni，保留家居产品的舒适感，不照搬沙发品牌、购物车和结算体系。
- 详细设计规则在 `设计规范.md`；所有颜色通过 CSS 语义变量维护。
- 官网不是 AI 产品营销页，助手只是服务入口，不占据主视觉。
- 官网内置悬浮窗口与 `/assistant` 完整页，不跨端口跳转，不用 iframe，不导入旧项目源码或样式。
- 消息、草稿、运行状态和 SSE 由应用级共享服务持有；组件卸载只能清理视图监听，不取消正在生成的回答。
- 完整页保留官网 Header 和简洁 Footer，仅消息区滚动；最近 10 条会话使用悬浮列表，不挤占正文，“查看更多”在独立弹窗中浏览、搜索与删除。悬浮机器人模式无历史切换。
- 助手 Markdown 先解析再净化，禁止原始 HTML 和危险链接，表格与代码块独立横向滚动；复制保持原始文本。
- 刷新恢复通过运行记录查询，不自动重新提交问题；网络不确定时保留幂等请求 ID，避免重复执行。
- 顶部在线咨询进入完整助手；会话路径为 `/assistant/:conversationId`，空白为 `/assistant`。ID 仅用来定位，不能代替后端访客 Cookie 鉴权；空对话隐藏新建按钮。
- 导航只保留首页、产品、关于我们、服务支持。
- 不添加新闻后台、登录、支付、购物车、评价、订阅或虚假客服电话。
- 移动端支持 375px；点击目标不小于 44px；支持键盘、可见焦点和减少动态效果。
- 图片有明确尺寸、替代文本与加载失败状态，正文不能依赖动画才可阅读。

## 产品与内容

- 产品唯一事实来源为 `/api/products` 和 `/api/products/:id`。请求失败必须显示重试，不使用硬编码目录假装加载成功。
- 美的和小米产品保留原名称、型号、来源；不宣称禾序生产、代理或与其合作。
- 描述可能是富文本，渲染必须经过净化。不能直接将 API 字符串传给 `v-html`。
- 外链只接受 HTTPS/HTTP URL，禁止 `javascript:` 等协议；新窗口带 `noopener noreferrer`。
- 未知价格、保修和库存必须说明未提供，不推算和伪造。
- `资料/` 为中文 Markdown 品牌和服务资料，只做少量主题分类。
- 虚拟品牌、学习用途与素材说明集中放在 Footer，不在正文重复展示注释或免责声明；下载文档保留事实来源、虚拟设定和核验日期。产品页保留原品牌和官方资料入口。
- 知识库导入是另一个操作；创建文档不等于自动发布进知识库。
- 文档与页面保持相同的品牌定位，避免混入旧“暖巢”文案。

## 开发与验证

```bash
npm ci
npm run dev
npm run build
npm test
```

- `npm run dev` 启动带崩溃重启的本地 Vite 服务；`npm run dev:once` 用于普通单进程启动。
- 检查首页、筛选与搜索、详情深链接、资料下载、404、接口异常、移动导航及聊天双模式接续。
- 保留使用者现有文件和工作区改动，不自动提交、推送或合并。
- 截图与临时验证放在父项目 `output/playwright/`，不将它们放进发布产物。
- 部署 SPA 时需要 history 回退及 `/api` 反向代理；本项目不取代服务端鉴权。
