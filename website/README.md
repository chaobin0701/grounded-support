# 禾序智能独立官网

独立的中文 Vue 3 + TypeScript + Vite npm 项目。视觉参考 Furni，以传统家庭电器企业官网为主体，内置悬浮机器人与完整对话页。当前项目位于原仓库的 `website/`，不依赖 `web/src`，拥有自己的依赖、锁文件与构建产物。

## 本地运行

要求 Node.js 22.18+ 或 24；安装与启动：

```bash
cd website
npm ci
npm run dev
```

官网预览：[http://localhost:8849](http://localhost:8849)。页面和样式支持 Vite 热更新，无需重建 Docker。

`npm run dev` 使用轻量进程监督器；子进程退出后尝试重启，连续三次启动失败停止，避免端口占用造成无限重试。健康检查每 15 秒报告当前页面状态，不重启现有后台。退出终端用 Ctrl+C。`npm run dev:once` 可使用普通 Vite 进程。

现有后台与助手仍在 8848，API 默认 3000，数据库继续沿用现有运行方式。产品接口必须在线，否则官网显示错误与重试，不使用假目录兜底。

## 页面与取舍

| 路由 | 内容 |
| --- | --- |
| `/` | 品牌主张、生活场景、精选产品、理念、服务入口 |
| `/products` | 分类、关键词、数量、产品网格；筛选同步 URL |
| `/products/:id` | 主图、介绍、参考价格、规格、官方资料与咨询 |
| `/about` | 公司介绍、名称含义、虚拟品牌历程 |
| `/support` | 中文资料下载、服务边界与常见问题 |
| `/assistant` | 同站点完整助手，历史会话、流式回答、引用和处理过程 |

剔除购物车、结算、支付、账户、订阅、客户评价、虚构团队、新闻管理与不必要轮播。本项目不复制 Furni 的整套商城。官网聊天前端直接复用已有聊天 API；后台、Agent 与原 8848 应用不改动。

## 内置双模式助手

- 所有官网咨询按钮与右下角机器人打开悬浮窗口，不离开官网。窗口只有当前会话，新建、完整助手和关闭三个操作，无历史切换。
- 完整助手使用相对路由 `/assistant`，沿用官网 Header 与简洁 Footer，不显示悬浮机器人；桌面显示窄会话栏，手机用顶部会话菜单。
- 应用级共享服务持有消息、草稿和 SSE。关闭窗口、切换官网页面或进入完整页不会中断请求，也不会重复发送。
- 新建只切换到本地空白状态；首次有效发送才调用会话创建接口。生成中禁止新建、切换和删除，但仍可输入下一轮草稿。
- `grounded.activeConversationId`、`grounded.pendingChatRequest`、`grounded.draftInput.*` 保存到本官网 origin 的 localStorage；不迁移旧 8848 的浏览器存储。访客身份沿用后端 HttpOnly Cookie。
- 刷新后仅查询消息与运行记录恢复。遇到 running 每 2 秒查询，达到期限或连续查询失败后停止加载并提供检查入口；不会自动重发问题。网络不确定时手动重试沿用原幂等 ID，已明确失败的运行使用新 ID。
- 小窗口只显示简短公开状态；完整页处理过程默认折叠。没有隐藏推理、系统 Prompt、原始工具参数展示，也不提供模型请求取消功能。
- 复制和删除通过统一通知反馈，删除操作针对用户选择的具体会话。

## 接口和配置

唯一产品来源为已有公开接口：`GET /api/products`、`GET /api/products/:id`。类别直接从目录提取；不硬编码四款产品到页面。聊天使用 `/api/chat/presentation`、`/api/chat/conversations`、会话的 messages/runs/DELETE，以及 `POST /api/chat/conversations/:id/messages/stream`。全部经同源代理访问，不需要浏览器跨域访问 3000 或跳到 8848。

复制 `.env.example` 为 `.env.local` 后按实际环境修改：

```ini
API_PROXY_TARGET=http://127.0.0.1:3000
```

`API_PROXY_TARGET` 仅用于开发和预览代理，配置变动需重启开发进程。旧 `VITE_ASSISTANT_URL` 已移除并不再读取；助手始终留在本官网。不要在前端环境变量放入密钥。

## 验证和静态发布

```bash
npm test
npm run build
npm run preview
```

`dist/` 为独立静态发布产物，预览端口 8850。生产托管须配置 SPA history 回退与 `/api` 反向代理，SSE 路由关闭缓冲并允许足够的请求时间，透传 Cookie 与 Set-Cookie；构建产物不含后台、数据库或鉴权系统。真实产品外链、外部图片和聊天依赖相应服务可达。

测试覆盖目录数据校验、筛选、类别、URL 协议、异常与取消、中文资料及独立项目约束。浏览器检查须另外验证桌面/手机排版、图片加载、深链接、资料下载、富文本净化和接口异常，不能仅用构建成功代替。
