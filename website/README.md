# 禾序智能独立官网

独立的中文 Vue 3 + TypeScript + Vite npm 项目。视觉参考 Furni，以传统家庭电器企业官网为主体，内置悬浮机器人与完整对话页。当前项目位于原仓库的 `website/`，不依赖 `web/src`，拥有自己的依赖、锁文件与构建产物。

## 本地运行

要求 Node.js 22.18+ 或 24；安装与启动：

```bash
cd website
npm ci
npm run dev
```

官网预览：[http://localhost:8849](http://localhost:8849)。页面和样式支持 Vite 热更新，无需重建 Docker。

页面正文不重复展示场景图注、虚拟品牌/学习用途说明、目录价格免责声明或助手输入提示说明；Footer 保留现有声明与设计参考。产品原品牌、官方资料链接、未知数据提示及可下载文档的事实说明不受影响。

基础页面使用 GSAP 入镜动效：首页首屏文字/场景图分步出现，品牌理念、产品卡片、服务资料和详情信息随进入视口轻微上移淡入，每个元素仅播放一次。助手空白欢迎区按“机器人图标 → 整句标题 → 副标题 → 快捷问题”顺序短暂交错地淡入上移，整体约 0.6 秒完成，没有打字机或光标；布局不跳动、屏幕阅读器读取完整文案，正文回答仍然使用原生 SSE。聚焦或提前点击欢迎区立即结束动画并允许操作，快捷问题异步更新不重播整段介绍。系统“减少动态效果”启用时不播放，动画中启用时立即恢复完整内容；路由切换和组件销毁清理动画/观察器/监听。没有预先隐藏基础页面正文、视差、滚动劫持或动画新增的接口请求。

`npm run dev` 使用轻量进程监督器；子进程退出后尝试重启，连续三次启动失败停止，避免端口占用造成无限重试。健康检查每 15 秒报告当前页面状态，不重启现有后台。退出终端用 Ctrl+C。`npm run dev:once` 可使用普通 Vite 进程。

现有后台与助手仍在 8848，API 默认 3000，数据库继续沿用现有运行方式。产品接口必须在线，否则官网显示错误与重试，不使用假目录兜底。

## 页面与取舍

| 路由 | 内容 |
| --- | --- |
| `/` | 品牌主张、生活场景、精选产品、理念、服务入口 |
| `/products` | 分类、关键词、数量、产品网格；筛选同步 URL |
| `/products/:id` | 主图、介绍、参考价格、规格、官方资料与咨询 |
| `/about` | 公司介绍、名称含义、虚拟品牌历程 |
| `/support` | 中文资料下载、服务边界与常见问题 |
| `/assistant`、`/assistant/:conversationId` | 同站点完整助手，历史会话、流式回答、引用和处理过程；URL 定位当前会话 |

剔除购物车、结算、支付、账户、订阅、客户评价、虚构团队、新闻管理与不必要轮播。本项目不复制 Furni 的整套商城。官网聊天前端直接复用已有聊天 API；后台页面、Agent 与原 8848 应用不改动，后端仅增加复用接入计量服务的 Cookie 状态/额度适配。

## 内置双模式助手

- 顶部“在线咨询”进入同站点完整助手；内容区咨询按钮与右下角机器人打开悬浮窗口。窗口只有当前会话、新建、完整助手和关闭操作，无历史切换；空白对话不展示新建按钮（完整页同样处理）。
- 完整助手使用相对路由 `/assistant`，沿用官网 Header 与简洁 Footer，不显示悬浮机器人。输入框上方的紧凑“新建会话＋最近会话”替代常驻侧栏；悬浮列表向上显示最近 10 条和更新时间，展开不会移动聊天正文或输入框。“查看更多会话”打开独立列表弹窗，支持搜索、切换和删除。
- 应用级共享服务持有消息、草稿和 SSE。关闭窗口、切换官网页面或进入完整页不会中断请求，也不会重复发送。
- 新建只切换到本地空白状态；首次有效发送才调用会话创建接口。生成中禁止新建、切换和删除，但仍可输入下一轮草稿。
- `grounded.activeConversationId`、`grounded.pendingChatRequest`、`grounded.draftInput.*` 保存到本官网 origin 的 localStorage；不迁移旧 8848 的浏览器存储。访客身份沿用后端 HttpOnly Cookie。
- 完整页首次发送后以 `/assistant/会话ID` 替换当前网址；切换历史会话同步路径，新建空白或删除当前会话回到 `/assistant`。深链接优先于本地上次会话，刷新只加载消息/运行记录，不重发问题。URL 不携带访客凭证，仅凭复制的链接不能在其他浏览器读取会话；后端仍验证会话与当前访客 Cookie 的归属。失效或其他访客的链接回到空白助手并提示，不自动创建会话。生成中进入完整页继续当前流，不能通过路径切换到其他会话。
- 刷新后仅查询消息与运行记录恢复。遇到 running 每 2 秒查询，达到期限或连续查询失败后停止加载并提供检查入口；不会自动重发问题。网络不确定时手动重试沿用原幂等 ID，已明确失败的运行使用新 ID。
- 小窗口只显示简短公开状态；完整页处理过程默认折叠。没有隐藏推理、系统 Prompt、原始工具参数展示，也不提供模型请求取消功能。
- 复制和删除通过统一通知反馈，删除操作针对用户选择的具体会话。
- 额度入口位于输入框上方，完整页放在“最近会话”旁边，以小进度条与占用百分比展示。点击向上展开“官网共享额度”浮层，查看今日次数/上限、Token 已用/上限、预留、剩余和北京时间重置时间，支持刷新、Escape 和点击外部关闭，不挤动输入框。Token 未设上限时显示“不限”并改用次数占比；不创建个人配额，不改管理员配置。进入助手、每轮结束/恢复、北京时间零点和临时状态重试时刷新；查询合并，不按 token 请求。网络失败显示未知和重试，不伪造零余额或阻断正常发送。额度和状态仅作快照，后端仍负责真正的资源限制。
- 用户与 AI 分别使用人物、机器人头像。助手回答支持 Markdown 加粗、标题、列表、表格、引用和代码块，流式文本同步渲染；复制保留原始回答。Markdown 使用独立 Marked 实例解析、DOMPurify 净化，禁止原始 HTML 和危险链接，不自动加载模型生成的图片；表格与代码块只在自身区域横向滚动。
- 产品卡片与详情页的“咨询产品”打开当前机器人并附加该产品，不自动发送问题，也不创建空会话。浮窗和完整页共用“引用产品”选择器：按钮打开搜索框，正文任意位置的单独 `/`（如 `21321 /`）或 `/小米` 等关键词打开列表，按名称、品牌和型号过滤。上下键选择、Enter 添加、Esc 关闭；添加仅替换光标处的斜杠命令，保留前后问题文字。普通产品名称、网址、日期、分数与代码不自动引用，中文输入法提交不会被误当作发送。
- 产品列表只读取真实 `/api/products`，每次打开重新加载，筛选不逐字请求。浮层向上覆盖、不改变输入框网格；小图失败有替代状态，加载失败可重试，无匹配结果不阻止关闭菜单后正常咨询。关联产品最多 5 个并去重，以原子内联引用穿插在正文中，可在换行后插入、通过拖动或剪切粘贴移动。标签无 ×，高度约 26px、无边框、小圆角、左右留有间距；引用后的 Backspace、引用前的 Delete 或选区删除都可移除引用，支持撤销/重做。文字、位置及产品 ID 一起保存，失败/刷新可恢复，历史用户消息按原位置展示。
- 发送的 `question` 保留产品名称和用户原有换行，例如 `这个产品怎么样\n米家电暖器`，不自动增加换行。产品 ID 独立放在 `context.productIds` 中驱动预查询；`context.productReferences: [{ productId, offset, length }]` 只标记完整正文里的名称范围（UTF-16，包含产品名称），渲染时将该文字变成标签，不再插入第二遍名称。编辑器内部的纯文本和位置单独保存用于草稿、失败恢复和重试，不作为新的消息正文。后台、模型输入和普通复制均能读取完整问题。历史的仅 offset 引用继续按旧位置插入名称，旧的仅 productIds 请求也兼容，不改写历史记录。
- 产品名称属于用户提问，不作为可信业务事实；不提交客户端价格、规格或工具结果。详情仍由后端按 ID 预加载、检查版本并跨轮复用，位置样式不影响工具执行和上下文权限。

## 接口和配置

唯一产品来源为已有公开接口：`GET /api/products`、`GET /api/products/:id`。类别直接从目录提取；不硬编码四款产品到页面。聊天使用 `/api/chat/presentation`、`/api/chat/conversations`、会话的 messages/runs/DELETE，以及 `POST /api/chat/conversations/:id/messages/stream`。状态和共享额度使用 `/api/chat/status`、`/api/chat/quota`，沿用当前访客 HttpOnly Cookie，复用 `/api/v1/agent/*` 同一接入服务；不在前端使用管理员令牌或平台 API Key。全部经同源代理访问，不需要浏览器跨域访问 3000 或跳到 8848。

复制 `.env.example` 为 `.env.local` 后按实际环境修改：

```ini
API_PROXY_TARGET=http://127.0.0.1:8081
```

`API_PROXY_TARGET` 仅用于开发和预览代理，配置变动需重启开发进程。旧 `VITE_ASSISTANT_URL` 已移除并不再读取；助手始终留在本官网。不要在前端环境变量放入密钥。

后端仍执行来源白名单校验。父项目开发监督进程的 `ALLOWED_ORIGINS` 已补充官网 8849 与构建预览 8850（localhost 和 127.0.0.1）；使用其他域名部署时需显式加入对应官网来源。不要通过移除 Origin 请求头或关闭校验绕过这一边界。

## 验证和静态发布

```bash
npm test
npm run build
npm run preview
```

`dist/` 为独立静态发布产物，预览端口 8850。生产托管须配置 SPA history 回退与 `/api` 反向代理，SSE 路由关闭缓冲并允许足够的请求时间，透传 Cookie 与 Set-Cookie；构建产物不含后台、数据库或鉴权系统。真实产品外链、外部图片和聊天依赖相应服务可达。

测试覆盖目录数据校验、筛选、类别、URL 协议、异常与取消、中文资料及独立项目约束。浏览器检查须另外验证桌面/手机排版、图片加载、深链接、资料下载、富文本净化和接口异常，不能仅用构建成功代替。
