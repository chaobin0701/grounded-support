# 禾序官网设计规范

更新日期：2026-10-08

## 设计定位

传统家庭电器企业官网，而不是 AI 产品首页或后台应用。视觉参考 [Furni / Untree.co](https://untree.co/demos/furni/)，借鉴其深色首屏、家居氛围、柔和背景与清楚的产品展示，重新实现中文内容及 Vue 页面。

视觉主张：深青绿、暖白、自然生活图像与有序留白，传递舒适、清晰和可靠感。

内容主张：品牌 → 产品 → 理念 → 服务；首页介绍品牌，产品页直接进入筛选和网格，不重复首页。

交互主张：GSAP 首屏分步淡入、内容入镜时轻微上移、导航下划线反馈、产品轻微悬停上浮。动效反馈操作，不制造装饰性噪声。

## 品牌与色彩

| 语义变量 | 色值 | 用途 |
| --- | --- | --- |
| `--brand` | `#176B5B` | 主操作、激活状态、链接 |
| `--hero` | `#23483E` | 首页大面积品牌底色 |
| `--mint` | `#E8F2EE` | 品牌理念及选中分类 |
| `--paper` | `#F7F8F4` | 主页面暖白底色 |
| `--ink` | `#202B28` | 标题与主要文字 |
| `--muted` | `#606E67` | 正文辅助信息 |
| `--line` | `#DCE3DD` | 细分隔线与输入框边界 |
| `--accent` | `#D69A3A` | 可选小面积琥珀点缀，当前不用于主要操作 |

主色只能有一个方向，不让不同按钮各用一种颜色。深色背景上的辅助文字需使用浅绿，不能沿用浅色页面灰字。

## 字体与网格

使用本地可用中文无衬线字体：Noto Sans SC、苹方、微软雅黑与系统回退，不外部下载整套中文字体。正文默认 16px、行高 1.75；辅助文字 12–14px，层级通过字号、字重和留白建立。

内容最大宽度 1200px，桌面左右至少 32px，移动端 20px。首屏背景通栏，文字与图像在内部网格对齐。常规区块纵向留白 88px，手机 60px。

产品网格：大屏四列、中屏两列、小屏一列。详情为主图与信息双列，移动端自然堆叠。不是所有内容都装卡片；品牌理念、服务和历史优先使用分隔线、列与列表。

## 页面构成

- 首页：品牌文字与生活场景图，两个主次操作，四款动态精选产品，品牌理念，资料与咨询入口。
- 产品中心：轻量标题，分类和搜索，产品数量，网格，参考价说明。无大 Banner。
- 产品详情：原品牌名称、主图、描述、参考价格、官方链接、规格和资料入口。
- 关于我们：名称含义、理念与品牌历程，不伪造资质和团队；虚拟设定说明集中在 Footer。
- 服务支持：资料下载、常见问题、能力边界。不用长表单收集敏感信息。
- 悬浮助手：400px 左右，单会话、简短过程状态、固定输入区；只有新建、完整助手、关闭操作。移动端适配视口与焦点范围。
- 完整助手：同站点 `/assistant`，无常驻侧栏与额外大标题。输入框上方放置紧凑的“新建会话＋最近会话”；可见高度 32px，保留 44px 的纵向点击范围。列表向上绝对定位覆盖正文，最多显示最近 10 条；“查看更多”打开带搜索、切换、删除的历史弹窗。展开与收起不改变正文及输入框位置。
- 消息使用人物和机器人头像，AI 正文开放排版，无大面积气泡。输入框左边缘对齐 AI 正文；完整与悬浮助手均不展示来源提示行，引用元数据仍保留用于后台调试。保留 Header 与紧凑 Footer，页面本身不滚动，消息、历史弹窗内容各自滚动。
- Markdown 按内容层级显示加粗、标题、列表、表格与代码块；模型原始 HTML 不渲染，链接仅允许 HTTP/HTTPS，表格和代码块不撑宽页面。
- 助手交互：窗口短暂淡入，按钮反馈与可见焦点；收起不取消生成，进入完整页自动收起窗口并继续同一流。无重复品牌头部或跨端口导航。
- 工具进度：模型通过原生 tool_calls 决策，同时可返回简短公开操作说明（commentary），在工具执行前独立展示；不展示推理、参数、内部 ID 或原始结果，不为说明额外调用模型。说明缺省或格式异常时仍继续有效工具调用，程序生成的标签只用于步骤状态和缺省反馈。第一版规划非流式，完整响应返回后才展示说明。完整助手的处理过程位于回答正文上方，模型公开说明在执行时直接显示；步骤执行中展开，结束后收起并保留公开说明。展开后每步仅为小型状态图标＋单行操作描述，长文字自然换行，无分隔横线、连接线、卡片、二级分类和右侧重复状态列；列表仅统计工具调用，不展示“回答生成”步骤；名称使用“查看产品分类”等中性描述，不添加“已”或“正在”前缀；已完成工具用扳手图标、运行中用加载图标，未完成保留明确文字及无障碍描述。等待状态不与当前步骤重复显示；悬浮助手显示最新公开说明和当前状态。前台不显示毫秒/秒耗时或结果数量，后台轨迹保留诊断信息。首轮尚无模型说明时显示“正在理解你的问题”，不猜测工具。公开说明按纯文本渲染、支持换行、礼貌通知且不抢焦点；来源提示仍隐藏。
- 基础页面入镜：单次播放，默认上移 20px、0.7 秒、`power2.out`；场景图 14px/0.85 秒，卡片错开 0.06 秒，最大延迟 0.18 秒。只对内容元素执行，不影响 Header、Footer、聊天记录或输入框；产品卡片通过外层动画容器避免影响原有悬停样式。无预先隐藏正文或动画控制滚动。
- 欢迎区：图标 0 秒开始，标题 0.08 秒、副标题 0.16 秒、快捷问题 0.24 秒开始；各元素淡入并上移 6–12px，按钮间隔 0.04 秒，整体约 0.6 秒完成。标题始终为完整句子，无打字机或光标。聚焦或点击立即跳过动画，不限制发送；异步快捷问题不重播介绍。完成后恢复内联样式，布局和完整文本始终保留。禁止给模型原生 SSE 人为加速/限速或模拟 token 动画。
- 输入框：24px 圆角、白底细边框，圆形发送按钮固定在框内右下角，不参与高度计算；文字区右侧预留按钮空间。空白和单行保持 62px，多行按实际折行高度自动增高，最多十行，超过后内部滚动。小视口或手机键盘出现时额外限制为 35dvh，避免占满聊天窗口。恢复草稿、切换会话、清空与窗口宽度变化均重新测量；不添加未实现的附件、语音或模型选择入口。
- 产品引用：输入框上方保留轻量“引用产品 /”入口，双模式共用选择器；任意位置的独立斜杠（包括数字之后）或按钮打开向上绝对定位的浮层，网址/分数/代码与普通名称不自动绑定。列表使用 40px 产品小图、名称和品牌/型号，不显示价格、长描述或多层卡片。列表内部滚动，根据聊天区域与手机可见视口约束高度；打开不推移正文、输入框或页面滚动位置。支持键盘上下键、Enter、Esc 与中文输入法，Esc 先关闭选择器再允许关闭机器人。最多 5 个产品，已选禁用并标记。标签按光标位置与正文交错，不固定在开头，允许换行、拖动和剪切粘贴；内部内容高度约束并独立滚动。标签无 ×、无边框、4px 小圆角、高约 26px，左右各留 4px 间距，长名称截断。Backspace/Delete、选区删除同步移除对应 ID，支持撤销/重做；草稿和历史均保留引用位置。来源只用真实产品接口。产品卡片咨询按钮为详情链接之外的独立按钮，不嵌套交互元素。菜单短暂淡入，减少动态效果时禁用过渡。
- 引用排版：标签继承所在正文或输入框的字号、字重和行高，图标使用 1em；标签与相邻正文垂直居中，去除标签额外上下留白，左右各保留 4px 间距。不使用整段 flex 居中，以免破坏原有换行和长消息阅读布局。
- 引用正文：发送和持久化的完整正文包含产品名称及原有换行，前台使用 `offset + length` 将对应文字范围显示为标签，不重复插入名称。普通复制、后台与模型输入均保留可读名称；独立 productIds 仍驱动后端预查询，前端名称不充当可信业务事实。旧的仅 offset 历史消息按插入语义还原，不改写数据库。
- 共享额度：输入框上方、“最近会话”旁的紧凑入口＋3px 小进度条，不新增常驻卡片或圆环。点击向上浮层展示“官网共享”、次数、Token、预留、剩余、北京时间重置时间与刷新按钮；浮层只覆盖内容，不参与布局，支持键盘与点击外部关闭。有限 Token 进度计入预留，没有 Token 上限时显示“不限”并用次数占比。接近上限使用克制琥珀色。错误/不完整计量显示可操作状态，不在查询失败时伪造零额度。
- 顶部在线咨询直接进入完整页；完整会话使用 `/assistant/会话ID` 路径，空白对话使用 `/assistant` 且隐藏新建按钮。分享路径不授予跨浏览器访问权限；访客 Cookie 归属仍由后端验证，失效链接显示可操作提示。
- 页脚：公司名称、基本导航、虚拟品牌与素材说明、设计参考署名。
- 页面正文不重复展示场景图注、学习用途、目录/价格免责声明及助手输入区注释；Footer 说明保留，产品原品牌、官方资料、未知数据与必要错误提示保留。

## 交互与无障碍

- 按钮、导航、移动菜单等独立操作区至少 44×44px。
- 激活状态不移动排版，键盘焦点有明确轮廓。
- 移动菜单有开关状态与 Escape 关闭，页面切换把焦点放到主要内容；移动聊天窗口约束 Tab 焦点，关闭恢复触发位置。
- 图片有尺寸与替代文本；主视觉优先加载，产品图延迟加载。
- 富文本描述净化后渲染，外链仅接受 HTTP/HTTPS，打开新窗口带隔离属性。
- 分类、搜索写入 URL；浏览器前进后退可还原。
- 加载、空结果、404、接口错误、图片失败分别展示，接口错误提供重试。
- `prefers-reduced-motion` 下关闭动画、过渡和悬停位移；JS 动画监听设置变化，立即结束并恢复文本/样式。键盘聚焦入镜元素时立即显现，组件卸载清理 Tween、IntersectionObserver 和监听。

## 删减与不做

不做购物车、结算、登录、订阅、客户评价、虚构员工、新闻后台、自动轮播、强视差、滚动劫持、粒子和复杂 3D。少图不等于无图，保留首页生活图及产品主图。

## 验收清单

- [ ] 375px、768px、1440px 无水平溢出。
- [ ] 首页与产品页职责不同，品牌和主要操作清楚。
- [ ] 目录与现有 API 同步，错误不使用硬编码产品伪装成功。
- [ ] 详情、搜索、分类、重试、移动导航与资料下载可操作。
- [ ] 七份中文 Markdown 可独立阅读，来源与虚拟信息边界明确。
- [ ] 无购物车或空壳交易入口；现有后台与助手不被改写。

具体本次运行验证记录见 `验证记录.md`；清单作为每次迭代的检查标准，不代表未来改动自动通过。
