## 明确限制

- 这是虚拟品牌学习官网，不是注册、生产、代理或商业合作的证明。
- 中文服务文档不是厂家说明书；完整安装与安全要求仍需核对官方文件。
- Markdown 规格是静态快照；后台修改后需要人工更新，页面目录则直接读取 API。
- 产品外部图片和官方链接受原网站可用性影响；当前无购物车、支付、库存与真实售后办理。
- 原记录为独立官网初版验证。后续双模式助手已替换跨端口入口，正式部署需配置 SPA 回退、同源 API 代理及不缓冲的 SSE。后续验证见本文件追加记录。
