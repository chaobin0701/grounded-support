# 服务支持与常见问题

更新日期：2026-10-08

内容性质：本学习项目的咨询与资料服务边界，不是原品牌售后政策。

## 可提供的帮助

查看品牌介绍与产品目录；解释已有规格字段；提供中文 Markdown 资料；通过现有助手查询产品和知识库。目录事实来自后台，文档是需要人工维护的内容资料。

## 不能提供的帮助

本站不能实际购买、收款、查询订单物流、办理退款换货、预约维修或创建原品牌售后申请。页面出现解释或建议，不表示真实业务已受理。

禾序为虚拟品牌，不提供真实客服电话、工厂、服务网点、营业时间或授权代理承诺。

## 咨询时提供哪些信息

优先提供产品全名与型号、想了解的字段、可描述的现象、发生时间，以及已查阅的官方资料。一次可以问多个问题，但不需要先提交订单号或个人资料。

不要在公开咨询中粘贴 API Key、密码、身份证、支付信息、完整订单记录和家庭住址。实际售后需要身份核验时，应转到原品牌或购买平台的正式受理渠道。

## 信息不足时的处理

1. 先区分能确认与不能确认的部分，回答已有资料支持的内容。
2. 说明缺少哪个型号、哪个参数或哪份说明，而不是机械地拒绝整个问题。
3. 如有必要，请用户补充最少的信息，例如型号或错误提示。
4. 涉及交易、保修、安装与维修时，指引核对官方来源，不编造处理结果。

这些是服务内容建议，不代表本文会自动修改 Agent 的运行规则；后续导入与行为配置仍需独立验证。

## 常见问题

### 禾序是一家真实公司吗？

当前是学习项目的虚拟品牌设定。公司名称、品牌故事和愿景用于官网与服务内容演示，不构成实际注册、生产、经营或资质证明。

### 产品是禾序生产的吗？

不是。当前四款目录产品来自美的、小米公开资料，保留原品牌、型号与参考链接，没有合作或代理关系。

### 官网价格能直接下单吗？

不能。美的 HFT20ZBJ 目录显示参考 ¥343，其余产品没有固定价格。参考价可能发生变化，应在购买时查官方销售渠道；网站没有支付功能。

### 产品数量为什么会改变？

官网使用后台产品目录接口，管理员新增、删除或调整公开产品后，页面重新加载即可读取相应数据。Markdown 文档不会自动更新，仍需人工核对。

### 保修多久？是否免费安装？

当前资料没有足够信息统一回答。以准确型号、购买渠道、时间和原品牌服务政策为准，不提供猜测的期限或费用。

### 产品说明书在哪里？

详情页提供官方参考链接。本站下载的 Markdown 是学习整理资料，不是厂家说明书；没有取得对应型号手册时要明确说明。

### 我的设备出现异常怎么办？

先确认型号与现象。涉及损坏、异味、电气或安装风险时，不建议自行拆修、短接或反复试运行，联系原品牌官方服务。本项目不能远程确认设备安全。

### 在线助手会记住我的会话吗？

本官网内置悬浮助手与 `/assistant` 完整页面，两种界面共用当前会话。关闭窗口不会停止生成；刷新后读取已保存消息与运行状态，不自动重复提交问题。浏览器本地保存当前会话标识和输入草稿，服务端会话仍遵循现有访客权限边界。不迁移旧站点浏览器存储，不能据此推定服务端数据保存期限或正式隐私条款。

页面动态目录与 Markdown 静态资料应分开管理。涉及新增产品、规格变化、品牌定位或实际经营政策，先核对来源，再更新相应文档并记录日期。安全与售后资料不得仅凭大模型扩写补充。
