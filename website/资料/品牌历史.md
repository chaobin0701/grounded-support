# 禾序智能｜品牌历史

更新日期：2026-10-08

内容性质：以下全部历程为虚拟品牌故事，不是公司注册、经营或商业活动记录。

## 故事起点

禾序的故事从一个平常的问题开始：为什么买一件家庭电器，需要理解那么多难懂的参数；为什么使用时遇到疑问，还要在不同页面之间寻找答案？

在这套品牌设定中，禾序把“让产品容易理解，让生活更有秩序”作为出发点。我们关注温度、空气与日常使用，希望把品牌介绍、产品资料和服务支持放在一个清楚的地方。

## 2024：确定生活方向

虚拟故事中的第一阶段是观察家庭生活需求。卧室取暖、书房安静使用、客厅空气循环，都不是单靠一个参数就能解释的场景。

这一阶段确定名称“禾序”，以及舒适、清晰、有序的内容方向。不设定真实成立日期、办公地点或创始团队，不虚构研发成果。

## 2025：整理产品与服务知识

第二阶段围绕取暖与空气两类场景组织资料：产品介绍、规格说明、使用前核对事项、日常维护和常见问题。

故事中的重点不是增加产品数量，而是建立信息边界：把品牌愿景与产品事实分开，把参考价格与真实售价分开，把咨询说明与实际售后办理分开。

## 2026：让官网成为服务入口

第三阶段的内容设定是建立中文官网。页面以品牌介绍和产品目录为主体，服务页提供 Markdown 资料，在线咨询在官网内复用已有聊天服务。

当前实现采用独立 npm 项目。产品页读取现有后台目录，保留原品牌与资料来源，不复制购物车、支付、订阅和其他暂不需要的交易功能。

## 当前项目的真实实现边界

以下是截至本次资料更新时的实现范围，而非上述虚拟经营历史：

- 官网页面：首页、产品中心、产品详情、关于我们、服务支持。
- 当前目录：两款取暖设备与两款空气设备，来自现有产品接口。
- 中文资料：品牌介绍、品牌历史、关于我们、选购规格、取暖使用、空气使用、服务常见问题。
- 在线咨询：官网内提供悬浮窗口与 `/assistant` 完整页面；复用现有后端，不新建一套 Agent。
- 交易：未实现购物车、支付、实时库存、订单处理和售后工单。

## 未来方向与未确认事项

可能继续完善型号核验、官方说明书整理、产品图片和服务信息。未来方向不是已完成成果，也不意味着一定上线。

如果以后开始真实经营，必须用经确认的注册信息、实际产品、授权与服务政策替换对应内容，不能把本故事直接变成正式企业履历。

## 使用这份资料的规则

官网展示历程时保留“虚拟品牌设定”标识。客服被问到成立时间、总部、工厂或合作关系时，应说明未提供真实企业资料，不从年份故事中推断。
